# Настройки парсинга — группировка по направлениям

**Дата:** 2026-07-29  
**Статус:** Утверждён к реализации  
**Ветка:** `staging` (crmparserv2)

## Проблема

Вкладка **Парсинг** в `Settings` перегружена: ключевые слова, блеклисты, реставрация и tip-правила идут длинным плоским списком из ~15 секций. Настройки одного бизнес-направления разбросаны, сложно редактировать связанные списки в одном контексте.

## Цель

Сгруппировать настройки по двум направлениям без изменения API и поведения парсера:

| Направление | Что входит |
|---|---|
| **Брендинг + Производство** | keywords, blacklist, restoration, tip-зоны PODRYAD / BANNERA / PROIZVODSTVO / PLENKA / RESTAVRACIYA |
| **Декор + МК** | decorKeywords, mkKeywords, decorBlacklist, mkBlacklist |

Общие настройки вкладки остаются снаружи групп.

## Не в scope

- Новые API, поля settings, миграции БД
- Переименование ключей (`keywords`, `decor_keywords`, …)
- Подвкладки, аккордеоны, drag-and-drop порядка
- Перенос «Расписание» / «Режим апрува» в другую вкладку

## Выбранный подход

**Вариант A:** две крупные секции-направления внутри вкладки `Парсинг`, внутри — существующие `Section` с прежней логикой.

Отклонены: подвкладки (лишняя навигация), аккордеоны (скрытые настройки).

## Структура вкладки «Парсинг»

```
Парсинг
├── [DirectionGroup] Брендинг + Производство
│   ├── Ключевые слова брендинга
│   ├── Блеклист позиций
│   ├── Реставрация
│   └── Tip-зоны (5 блоков TipRulesSection)
├── [DirectionGroup] Декор + МК
│   ├── Ключевые слова декора
│   ├── Ключевые слова МК
│   ├── Блеклист декора
│   └── Блеклист МК
├── Расписание парсинга
└── Режим апрува
```

## UI

### `DirectionGroup`

Обёртка в `Settings.jsx` (локальный компонент, без отдельного файла, если не разрастётся):

- `title` — заголовок направления (`text-lg font-semibold`)
- `description` — одна строка пояснения
- `children` — вложенные `Section`
- Внешний отступ между направлениями: `mb-8`
- Визуально: можно лёгкая рамка/фон `surface` или только заголовок + отступ — на усмотрение реализации, без тяжёлого chrome

### Tip-зоны

Константа `TIP_ZONES` остаётся источником конфигурации. Для рендера в брендинг-блоке фильтровать все зоны (все текущие относятся к брендингу/производству). Декор/МК tip-зон нет.

### Тексты

Заголовки направлений:

- **Брендинг и производство** — «Ключевые слова, блеклист, реставрация и правила типов для основного потока и печати»
- **Декор и МК** — «Ключевые слова и блеклисты для доски «МК и Декор»»

Существующие заголовки подсекций (`Ключевые слова брендинга`, …) не менять.

## Техническая реализация

**Файл:** `frontend/src/pages/Settings.jsx`

1. Добавить компонент `DirectionGroup({ title, description, children })`.
2. В `activeTab === 'parsing'` обернуть секции в два `DirectionGroup`.
3. Перенести блок «Реставрация» внутрь брендинг-группы (между блеклистом и tip-зонами).
4. Хуки, state, handlers — без изменений.
5. Smoke: открыть Настройки → Парсинг, проверить добавление/удаление keyword и blacklist в обоих направлениях.

## Критерий готовности

- На вкладке «Парсинг» видны два явных блока направлений.
- Все прежние списки доступны и работают как до рефакторинга.
- «Расписание» и «Режим апрува» остаются внизу вкладки вне групп.
